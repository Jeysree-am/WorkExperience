## This Repository contains scalable, enterprise-grade automation framework built using Playwright. It is designed to support UI.
# Key Features
*Page Object Model (POM)
*Base page abstraction
*Modular and reusable design
# Cross Browser Testing
Chromium
Firefox
WebKit
# Environment configuration
.env Based config
# Tag Based Execution
@smoke
@regression
@sanity
# Reporting
JSON reports
HTML reports
Screenshots and video capture on Failure
# Screenshots of Playwright show-report on sucessful execution on parallel execution

### Framework Design Highlights
🔹 Custom Fixtures
Automatic injection of Page Objects
Clean and reusable test setup
🔹 Base Page
Common actions (click, fill, wait)
Reduces code duplication
🔹 Config-Driven Execution
Centralized configuration
Environment-based runs
